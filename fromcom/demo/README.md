# FromCom – uuden sivuston malli (demo)

Lähde: https://www.webfindemot.fi/fromcom-demosivu (talletettu 19.11.2026)

Tähän kansioon on otettu talteen demosivun kaikki materiaali jatkokehitystä varten.
Demossa on valmiina vain **etusivu**. Alasivujen linkit (palvelut, kalusto,
referenssit, yritys, yhteystiedot, tietosuoja) palauttavat 404 – ne pitää vielä tehdä.

| Tiedosto / kansio | Sisältö |
| --- | --- |
| `sisalto.md` | Kaikki sivun tekstit osioittain, myös tarjouslomakkeen ja pikaoppaan tekstit |
| `tekniikka.md` | Tekniikka, värit, fontit, komponentit ja toiminnallisuudet |
| `kuvat/` | Kaikki kuvat alkuperäiskoossa, logo, Pirkanmaan kartta, kumppanilogot |
| `kuvakaappaukset/` | Kuvat sivusta tietokoneella ja puhelimella |
| `alkuperainen/` | Sivun HTML, FromCom-tyylitiedosto (CSS) ja sivun JavaScript viitteeksi |

Tiedostot `alkuperainen/`-kansiossa ovat Next.js:n tuottamaa käännettyä koodia.
Niitä ei ole tarkoitus muokata, vaan käyttää mallina uutta toteutusta tehdessä.
